# 汴水虹市 2.0

**春水穿桥过，百业向河生。**

一座取意于《清明上河图》虹桥段的可交互三维体素市井。木拱虹桥串起两岸街巷，货船降桅穿桥，行人与挑夫沿桥面和岸边活动。建筑、货物、人物、水纹、灯晕与舟船均由程序生成。

2.0 在原有微缩场景上加入 **晨曦 / 晴昼 / 灯夕、五则风物导览、随船镜头、PNG 留影**，并完成招牌图集合批、按需渲染、移动端与键盘体验、自动画质和中文压缩包修复。

## 直接观赏

双击 **`汴水虹市.html`** 即可在现代浏览器中打开。推荐使用启用了硬件加速的 Edge、Chrome 或 Firefox。作品使用 WebGL 2。

**交付 HTML 不需要安装、不需要启动服务器，也不需要联网。** JavaScript、Three.js、样式、招牌图集生成代码与许可证全部内嵌；没有 CDN、远程图片、字体下载或其他运行时资源文件。

归位只恢复相机，不重置模拟时间。暂停会同时冻结行人、船只、桅杆、船工、水纹、尾迹、茶烟与风动；相机和界面操作仍然可用，静止场景不持续重绘。

系统开启“减少动态”时，作品初次打开即暂停，环境与视角切换不使用平滑转场。点击播放是后续的主动选择。

## 场景与游历

- **虹桥**：26 个场景单位的连续跨径、5 道纵向拱肋、交错木构、横梁、斜向联系、逐块铺板、栏杆与桥头石基。桥面中央留出连续走道，两侧设 8 个摊位。
- **两岸**：18 组建筑，包括双层茶坊、临河客舍、布庄、食店、鱼行、粮栈、陶器铺和后院。屋顶采用阶梯瓦面、脊线与翘角，侧墙设木框、格窗和后门。
- **市集**：果物、蔬菜、鱼货、茶食、布匹、陶器、粮货 7 类陈列。可近看竹筐、布卷、陶罐、茶杯、麻袋、木箱、手推车与晾衣。
- **人物**：101 名三维人物，其中 46 名沿明确路线步行；另有摊主、顾客、围桌茶客、桥边观船人、搬货脚夫与船工。服装、身高、步速、动作相位和姿态存在变化。
- **舟运**：4 艘船。主货船沿两条行船线和两端转弯水域连续往返，接近虹桥时降桅，驶离后升起；船只轻微起伏，尾迹按照实际路径生成。两处装卸码头和一处小舟落脚点对应石阶、系缆与搭板。
- **环境**：三套独立光照与色调，22 处灯笼光晕、3 处茶坊烟源、轻微风动的树冠，以及由同一模拟时钟驱动的水面明暗与波纹。灯夕是温暖的傍晚演绎，不是全黑夜景。
- **风物志**：虹桥营造、桥上百业、茶烟巷口、一船春水、河岸日常五则原创短文与独立近景。导览不会自动翻页，可随时退出或手动探索。

作品是基于画作意象的原创空间演绎，木拱与建筑做了艺术化简化，并非历史测绘、工程复原或受力模拟。

## 画质与性能

- 36 面招牌合并为一张程序生成的纹理图集（29 个独立文字图块），颜色与阴影通道各只需一次招牌绘制。
- 静态建筑使用实例化批次；673 个树冠体素单独合批并同步风动阴影；人物使用一个动态实例化批次，船体分别合批。灯晕和茶烟各使用一次绘制。
- 自动画质在小屏或触控设备上采用均衡档；持续高帧间隔时逐级降低内部档位，避免反复升降。也可以手动锁定精致或流畅。
- 精致 / 均衡 / 流畅分别使用最高 1.7 / 1.25 / 1.0 的设备像素比，以及 4096 / 2048 / 1024 的阴影图。实际像素比不会超过设备能力。
- 流畅档保留低成本阴影，减少水面细节、风动和次要烟雾效果，而不是直接关闭全部阴影。
- 页面后台不推进模拟；恢复时重置帧计时。暂停且相机静止时按需渲染。

当前版本在本机验收中的精致档绘制调用为 **32（含阴影）**，上一版为 99。该对比来自同一开发环境，不代表所有设备的帧率保证；完整实测见 `artifacts/`。

## 开发与重新构建

已在 Node.js 24.19.0 下实际构建。重新开发需要 Node.js 与 npm；构建和验收依赖通过 npm 安装。

```powershell
cd "."
npm ci
npm run build
npm start
```

然后访问 **http://127.0.0.1:4173**。按 `Ctrl + C` 停止本地服务。

`npm run build` 使用 esbuild 将 Three.js 和所有源码合并，重新生成根目录的 `汴水虹市.html`。服务器只是开发预览的便利入口，每次请求都会读取最新 HTML；直接打开 HTML 仍是正式交付的运行方式。

常用命令：

| 命令 | 用途 |
| --- | --- |
| `npm run build` | 重新生成离线单文件 HTML |
| `npm start` | 启动本地预览服务 |
| `npm run preview` | 快速生成固定时刻截图与预览诊断 |
| `npm test` | 完整浏览器行为、离线和空间验收 |
| `npm run test:server` | 验证预览服务与交付 HTML 逐字节一致 |
| `npm run verify` | 构建、浏览器验收、服务验收 |
| `npm run package` | 完整验证后生成 UTF-8 项目 ZIP |
| `node package.mjs` | 仅重新打包当前已完成验证的文件 |

## 实际验证

验收在 Microsoft Edge 无界面浏览器中执行。测试把 HTML 单独复制到新建临时目录，以 `file://` 加载并拦截 HTTP/HTTPS 请求，确认 **外部资源请求为 0、控制台错误为 0**。

当前共 **22 组浏览器检查**，覆盖：

- 离线加载、版本、场景数量、图集和着色器实际生效。
- 全部步行路线，以及主船完整航线的 640 个姿态、两端转弯、靠泊船间距与穿桥净空。
- 暂停前后模拟时钟、人物、环境时钟、渲染帧数和图像哈希一致；恢复播放及 1× / 2× / 4× 推进。
- 三种环境实际画面差异、平滑切换、降桅和尾迹方向。
- 真实鼠标旋转、缩放、平移、五个预设视角、归位和键盘操作。
- 原生对话框的焦点进入、Tab 约束、快捷键隔离、Esc 关闭与焦点恢复。
- 五则导览、前后导航、随船位置跟踪与拖拽退出。
- 真实 PNG 下载、文件头、尺寸和字节数。
- 自动 / 精致 / 流畅画质，320×568、390×844、844×390、1024×768 布局，以及设备像素比为 2 的触控上下文。
- 系统减少动态偏好与即时无转场操作。

测试默认使用 Windows Edge：`C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`。路径不同时可设置：

```powershell
$env:BROWSER_PATH = "你的 Chromium 或 Edge 可执行文件完整路径"
npm test
```

截图和报告写入 `artifacts/`。步行路线检查建筑、摊位、茶桌与手推车的空间占用；航道检查使用保守船体矩形、实际渲染船体和桅杆顶点，以及船工高度上界。它们不代替完整人群避让或工程安全验证。

`package.mjs` 只使用 Node 标准库，显式写入 UTF-8 ZIP 条目，再读回每个文件验证名称、CRC 与内容。压缩包中的 HTML 与根目录交付 HTML 逐字节一致，且不包含 `node_modules`、旧 ZIP 或校验报告自身。
